# TimeFlow — 成大生修課與畢業規劃系統

專為國立成功大學學生設計的多學期修課規劃工具：排課、找課、衝堂與先修檢查、成績結算，以及大學部與研究所的畢業門檻檢核，全部在瀏覽器裡完成。

- 線上使用：<https://mrfox1122-love.github.io/NCKU_schedule/>
- 可安裝成 PWA（桌面或手機主畫面），離線也能開啟
- 不需註冊、沒有後端，所有資料只存在你自己的瀏覽器

> ⚠️ 本系統為學生個人製作的輔助工具，非學校官方系統。畢業規定、課程資料與檢核結果僅供參考，請以學校、各學系及課程查詢系統的最新公告為準。

## 主要功能

### 一、多學期排課工作台

- **多學期規劃**：一上到四下（或研究所碩一、碩二）各自排課，支援拖曳調整時段。
- **暫定時段**：同一門課有多個時段可先都排進去比較，選上後一鍵轉為正式課程並清掉其他候補。
- **衝堂即時提醒**：時間重疊的課程會立即標出。
- **網格／清單切換**：支援中午 N 節、夜間 A～D 節與週末顯示。
- **匯出圖片／桌布**：多種版面，可匯出單一學期或整份規劃。

### 二、找課

- **本學期開課**與**歷年課程**兩種資料來源，可依系所、年級、學分、星期、節次、上下學期、課程類別篩選，也能只看不衝堂的課。
- **歷年開課規律**：顯示「每年上學期」「近 4 年開 2 次」等資訊，方便規劃還沒開課的學期。
- 歷年課程依**班別**分開列出，不同教師、時段的同名課程不會混在一起。
- **候選課**：先把有興趣的課加入候選，並記錄是從哪裡加入的；可將多門候選課並排**比較**時段、學分、先修條件與衝堂情形。
- 一鍵**排入**指定學期，類別（必修／選修／本系／外系）依課程資料自動判定。

### 三、先修與課程地圖

- **先修檢查**：排課時自動比對課程資料中的「需先修以下科目」，未修過或分數未達門檻會提醒。
- **先修課程地圖**：以圖形顯示本系課程的先修關係，點一下標出整條先修鏈；已排進課表的課**連按兩下**可直接跳到該學期。
- **課程地圖（必修）**：依各學系官方「各學年度入學生必修科目表」，按年級與上下學期列出該屆必修，標示已修、已規劃、未排，並包含 N 選 M 必修群組與系定必選。
  - 已收錄電資、工、理、文、社科、管理、規設、生科、醫學院共 43 個學系／學程；尚無科目清單的學系會改由開課資料推估，並註明。
  - 整理時無法確定的規定會在地圖下方列出「規定未明確之處」。
- 地圖上的課都能直接按「找課」跳到找課頁。

### 四、畢業學分檢核

- **大學部**：選擇學系與入學學年，自動套用該屆的必修、必選、本系選修、外系承認上限等規定。
  - 通識：五大領域修讀狀況、跨領域數量、各系不承認科目過濾。
  - 英文免修、英檢門檻、服務學習、體育等校定項目。
- **研究所**：收錄 135 個碩、博士班的畢業規定，包含本所必修、論文學分、外所承認上限、專題研討次數等；整理時的不確定處會清楚註記。
- **找課補足**：未達標的項目旁有按鈕，直接帶入條件到找課頁。
- **必修排程檢查與修業時程**：檢查必修是否排在有開課的學期，並列出建議時程（僅供參考）。
- **轉系／雙主修試算**：用目前修課紀錄試算轉到其他學系或加修雙主修後的達成情況；轉系成功後可一鍵**套用**，並保留可還原的備份。

### 五、成績與 GPA

- **學期成績結算**：輸入百分制分數，換算等第績點（4.3 制）與學期、歷年加權平均。
- **成績趨勢圖**與**修業檢核報表**。
- **目標 GPA 倒推**：輸入預計學分與期望 GPA，反推之後各學期需要的平均。
- **隱私模式**：一鍵模糊所有分數與 GPA，方便在公開場合使用。

### 六、其他

- 十多款深淺色主題（夜幕紫、深海藍、冰川晴空、晨霧灰藍等）。
- 完整 JSON 匯入／匯出備份。
- 設定頁附資料來源、法規依據、常見問題與使用者條款。

## 快速開始

### 線上使用

直接開啟 <https://mrfox1122-love.github.io/NCKU_schedule/>。
在瀏覽器網址列或選單選擇「安裝」即可加到桌面／主畫面。

### 本機執行

本專案是純前端靜態網頁，不需要建置步驟，但 Service Worker 需要透過 HTTP 伺服器提供：

```bash
python -m http.server 8000
```

然後開啟 <http://localhost:8000>。

### 第一次使用

1. 到「系統設定」選擇學制（大學部／研究所）、學系與入學學年。
2. 在「找課」搜尋課程並排入學期，或在規劃頁手動新增課程。
3. 到畢業檢核查看各項目的達成狀況，未達標項目可按「找課補足」。

## 資料與隱私

- 所有課表、成績與設定只存在瀏覽器的 LocalStorage，不會上傳到任何伺服器。
- 清除瀏覽器資料或更換裝置前，請先到設定頁**匯出 JSON 備份**。
- 匯入的資料會經過格式檢查與跳脫處理；`security.json` 是用來測試 XSS 防護的惡意資料範例，請勿當成一般備份使用。

## 專案結構

```
├── index.html                 # 單頁應用主頁面
├── sw.js                      # Service Worker（離線快取，快取名稱含版本號）
├── manifest.webmanifest       # PWA 設定
├── css/                       # 樣式與主題 tokens
├── icons/                     # App 圖示
├── js/
│   ├── app.js                 # 視圖切換、學期切換等全域操作
│   ├── core/                  # 資料存取、彈窗、設定、安全處理
│   ├── schedule/              # 課表、衝堂偵測、圖片匯出
│   ├── course/                # 課程編輯、候選課與比較、先修檢查
│   ├── discover/              # 找課；catalog-data.js / history-data.js 為自動產生的課程資料
│   ├── analytics/             # 成績結算、圖表、報表
│   ├── graduation/
│   │   ├── graduation*.js     # 大學部畢業檢核
│   │   ├── rules-data/        # 大學部各學院學分規則
│   │   ├── required-courses/  # 大學部各學院必修科目表（課程地圖用）
│   │   ├── master/            # 研究所檢核與規則資料
│   │   ├── course-map.js      # 課程地圖
│   │   ├── prereq-map.js      # 先修課程地圖
│   │   ├── planning-assist.js # 找課補足、必修排程檢查
│   │   └── what-if.js         # 轉系／雙主修試算與轉系套用
│   └── libs/                  # Chart.js、html2canvas
└── tools/                     # 課程資料更新工具（Python）
```

所有腳本都以一般 `<script>` 依序載入、透過 `window` 共用函式，沒有打包工具或外部相依套件。

## 資料維護

### 課程資料（每學期／每學年）

找課使用的本學期開課與歷年課程資料，由 `tools/` 內的工具解析**自行存下的課程查詢頁面**產生。完整步驟見 [tools/README.md](tools/README.md)。

> 學校課程查詢網站禁止爬蟲，所有工具都只處理本機檔案，請不要改成自動抓取。

### 畢業規則

| 內容 | 位置 |
|---|---|
| 大學部學分規則 | `js/graduation/rules-data/<學院>.js`，以「入學學年 + 4」為鍵（例如 114 入學 → `'118'`） |
| 大學部必修科目表 | `js/graduation/required-courses/<學院>.js`，以 `registerRequiredCourses()` 註冊，`fromYear` 為適用的入學學年起點 |
| 研究所規則 | `js/graduation/master/rules-data/<學院>.js` |

新增或修改必修科目表時，請確認：

1. 各版本必修學分合計與該屆學分規則的 `requiredCredits` 一致。
2. 課名與課程資料中的名稱相同；改名或寫法不同的課以 `aka` 列出其他名稱。
3. 無法確定的地方寫進 `uncertain`，會顯示在課程地圖上提醒使用者。
4. 新的學院檔需同時加到 `index.html` 的 script 清單與 `sw.js` 的快取清單。

## 開發說明

### 版本更新

版本號出現在各檔案開頭註解、`sw.js` 的 `CACHE_NAME` 與頁尾。發布新版時三者需一起更新，使用者重新整理後才會拿到新的快取。

### 測試時的快取

Service Worker 採 stale-while-revalidate，修改檔案後瀏覽器可能仍顯示舊版。測試前可在開發者工具執行：

```js
for (const r of await navigator.serviceWorker.getRegistrations()) await r.unregister();
for (const k of await caches.keys()) await caches.delete(k);
location.reload();
```

若仍載入舊檔，請用「清除快取並強制重新載入」，或改用另一個連接埠開啟。

### 程式風格

- 原生 JavaScript，無框架、無建置流程。
- 檔案使用 CRLF 換行，請保持一致。
- 插入畫面的文字一律經過 `escapeHTML()`。

## 資料來源與免責聲明

- 課程資料：國立成功大學課程查詢系統（本學期開課與歷年課程查詢），由使用者手動存檔後解析。
- 畢業規定：各學系公告的修業規定、必修科目表、畢業學分檢查表與學生手冊。
- 本系統為非官方的學生自製工具，與國立成功大學無隸屬關係。規定可能隨學年度調整，實際修課與畢業資格請以學校及各學系最新公告為準。
- 發現規定或資料有誤，歡迎透過設定頁的回報表單告知。
