# NCKU_schedule

## 主要功能

### 一、多學期排課工作台
1. 多學期自由規劃：支援跨學期排課與滑鼠拖曳調課，換時間更直覺。
2. 暫定候補時段：同一門課有多個時段想先排進去比對？可先設為「暫定時段」，確定選上後一鍵轉為正式課程，自動清理其他候補。
3. 衝堂即時預警：自動抓出時間重疊的課程。
4. 網格／時間軸切換：可切換經典課表或清單檢視，並支援中午 N 節、夜間 A~D 與週末切換。

### 二、各系畢業學分自動檢核
1. 內建成大各系規章：選擇科系與入學年份，自動套用必修、必選修、本系選修與外系承認上限。
2. 通識學分檢核：自動計算五大領域修讀狀況、跨領域數量（需 ≥3 領域）與各系不承認科目過濾。
3. 加修與免修連動：支援英文免修（依校規自動轉為通識目標）、英檢達標，以及雙主修／輔系設定。

### 三、成績結算與 GPA 試算
1. 學期成績批次結算：輸入百分制分數，即時換算等第績點（4.3 制）與學期／歷年加權平均。
2. What-If 目標 GPA 倒推模擬：輸入未來的預計修讀學分與期望畢業 GPA，自動反推後續學期平均需維持幾分。
3. 成績隱私模式：在公開場合或跟朋友討論課表時，一鍵將所有分數與 GPA 模糊化。

### 四、實用小細節
1. 高畫質圖片匯出。
2. 12 款深淺色主題：夜幕紫、深海藍、冰川晴空、晨霧灰藍等主題隨意換。
3. 本地儲存：全站無資料庫，所有課表與成績純儲存在瀏覽器 LocalStorage，並支援完整 JSON 匯入／匯出備份。
