課程頁面下載書籤

把下面的按鈕拖曳到瀏覽器的書籤列（書籤列沒顯示的話按 Ctrl+Shift+B）：

📥 存課程頁

直接點這個按鈕不會有作用，一定要拖到書籤列。

使用方式

  1. 打開 course.ncku.edu.tw/index.php?c=qry_all，點進一個系所。
  2. 等課程列表完全載入。
  3. 按書籤列上的「📥 存課程頁」，會自動下載成 E2.html 這類檔名，並回到系所列表。
  4. 直接點下一個系所，重複以上步驟。
  5. 全部存完後，把下載的檔案搬到學期資料夾（例如 115-1/），再到 TimeFlow 資料夾執行 python tools/update_course_data.py current ../../課程資訊/115-1（詳見 tools/README.md）。

歷年課程查詢

  1. 打開 course-query.acad.ncku.edu.tw/index.php?c=qry11225，選學年期範圍與系所後送出查詢。
  2. 一直捲到最底（可按住 End 鍵），直到出現「已載入全部課程」。請不要捲太快，學校有請求頻率限制。
  3. 按「📥 存課程頁」，確認檔名（例如 E2_11101-11402）後下載。
  4. 若出現「已達本次載入上限」，請縮小學期範圍分次查詢。
  5. 存到歷年資料夾（例如 old/）後，到 TimeFlow 資料夾執行 python tools/update_course_data.py history ../../課程資訊/old。

書籤只會把「你目前開著的這一頁」存成檔案，不會自動去開其他系所，也不會對學校網站發出任何請求。

小技巧：在 Chrome 設定 →「下載」把下載位置改成學期資料夾，就不用再搬檔案；第一次下載時若詢問「允許下載多個檔案」，請選允許。
